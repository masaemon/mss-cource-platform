## 使い方

### 1. チケットの進捗管理

各チケットにはTodoリスト（チェックボックス）が含まれています。完了したタスクは `[ ]` を `[x]` に変更してください。

```markdown
- [ ] 未完了のタスク
- [x] 完了したタスク
```

### 2. 実装順序

基本的には **Phase 1 → Phase 2 → Phase 3 → Phase 4 → Phase 5** の順番で実装することを推奨しますが、必要に応じて順序を変更しても構いません。

### 3. チケットの内容

各チケットには以下の情報が含まれています：

- **概要**: チケットの目的
- **実装内容**: 実装すべき機能のチェックリスト
- **ファイル構成**: 作成・編集するファイルの構造
- **コード例**: 実装の参考となるコードスニペット
- **注意事項**: 実装時の重要なポイント
- **テスト項目**: 実装後に確認すべき項目
- **参考**: 関連ドキュメントへのリンク

### 4. 依存関係

一部のチケットは他のチケットに依存しています：

- **02（認証）** は **01（Supabase）** に依存
- **04-07（コアフィーチャー）** は **01-03（基礎構築）** に依存
- **08-10（管理機能）** は **02（認証）** に依存
- **11-12（コメント）** は **04（コース詳細）** に依存
- **13-15（仕上げ）** は全体が完成してから実装推奨

## 進捗の追跡

### 推奨する進捗管理方法

1. **各チケットのチェックボックスを更新**
   - 完了したタスクは `[x]` にマーク

2. **完了したチケットにマークを追加**
   - ファイル名の最初に `[DONE]` を追加（任意）
   - 例: `[DONE] 01-supabase-setup.md`

3. **問題や質問をメモ**
   - 各チケットの最後に「## メモ」セクションを追加
   - 実装中の気づきや問題点を記録
