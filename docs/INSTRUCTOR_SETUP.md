# 講師アカウントの作成方法

## 概要

MSS Course Platformで講師としてコースを作成・管理するには、ユーザーアカウントを「講師」ロールに昇格させる必要があります。

## 前提条件

- Supabaseプロジェクトがセットアップされていること
- データベースマイグレーションが適用されていること
- 管理者アカウントが存在すること（初回のみ手動で作成）

## 方法1: 管理者ダッシュボードから昇格（推奨）

### ステップ1: 管理者としてログイン

1. 管理者アカウントでログイン
2. `/admin/dashboard` にアクセス
3. 「ユーザー管理」をクリック

### ステップ2: ユーザーを講師に昇格

1. ユーザー一覧から対象のユーザーを探す
2. ロールのドロップダウンメニューから「講師」を選択
3. 確認ダイアログで「OK」をクリック

これで、そのユーザーは講師としてログインできるようになります。

## 方法2: Supabase Studioから直接変更

### ステップ1: Supabase Studioにアクセス

1. Supabaseプロジェクトのダッシュボードにログイン
2. 左サイドバーから「Table Editor」を選択
3. `profiles` テーブルを開く

### ステップ2: ロールを変更

1. 対象ユーザーの行を見つける（emailで検索可能）
2. `role` カラムをクリック
3. `instructor` に変更して保存

## 方法3: SQLクエリで変更

### Supabase SQL Editorで実行

```sql
-- 特定のメールアドレスのユーザーを講師に昇格
UPDATE profiles
SET role = 'instructor'
WHERE email = 'user@example.com';

-- 確認
SELECT id, email, role
FROM profiles
WHERE email = 'user@example.com';
```

## 初回の管理者アカウント作成

最初の管理者アカウントは手動で作成する必要があります。

### SQLで作成する場合

```sql
-- 1. まず、ユーザーをSupabase Authで作成（サインアップページから登録）

-- 2. 作成したユーザーを管理者に昇格
UPDATE profiles
SET role = 'admin'
WHERE email = 'admin@example.com';

-- 確認
SELECT id, email, role
FROM profiles
WHERE email = 'admin@example.com';
```

## ロールの種類

| ロール | 権限 |
|--------|------|
| `user` | コース閲覧、動画視聴、コメント投稿 |
| `instructor` | userの権限 + コース作成・編集、動画管理、コメント回答 |
| `admin` | instructorの権限 + ユーザー管理、全コース編集 |

## 確認方法

### 1. プロフィールページで確認

ログイン後、プロフィールページ（`/profile`）で自分のロールが表示されます。

### 2. ヘッダーメニューで確認

講師または管理者の場合、ヘッダーのユーザーメニューに以下が表示されます：

- **講師**: 「講師ダッシュボード」リンク
- **管理者**: 「講師ダッシュボード」 + 「管理ダッシュボード」リンク

### 3. ダッシュボードへのアクセス

- 講師ダッシュボード: `/instructor/dashboard`
- 管理ダッシュボード: `/admin/dashboard`

ロールが正しく設定されていれば、これらのページにアクセスできます。

## トラブルシューティング

### 「Forbidden」エラーが表示される

- **原因**: ロールが正しく設定されていない
- **解決策**: Supabase Studioで `profiles` テーブルの `role` カラムを確認

### ダッシュボードのリンクが表示されない

- **原因**: セッションが古い可能性
- **解決策**: 一度ログアウトして再ログイン

### ロールを変更しても反映されない

- **原因**: キャッシュの問題
- **解決策**: ブラウザをリロードするか、シークレットモードで試す

## セキュリティ上の注意

1. **管理者権限の付与は慎重に**
   - 管理者は全ユーザーのロールを変更できます
   - 信頼できる人にのみ管理者権限を付与してください

2. **講師権限の管理**
   - 講師は全コースを作成・編集できます
   - コンテンツの質を保つため、講師の選定は慎重に

3. **RLSポリシーの確認**
   - データベースのRow Level Security（RLS）ポリシーが有効になっていることを確認
   - 不正なアクセスを防ぐため、定期的にログを確認

## 次のステップ

講師アカウントを作成したら：

1. `/instructor/dashboard` にアクセス
2. 「新しいコースを作成」ボタンをクリック
3. コース情報を入力
4. 動画を追加
5. コースを公開

詳細は `docs/08-instructor-course-management.md` を参照してください。

## サポート

問題が発生した場合：

1. Supabase Studioの「Logs」でエラーを確認
2. ブラウザのコンソールでエラーを確認
3. `profiles` テーブルでデータを確認
4. Middlewareが正しく動作しているか確認
