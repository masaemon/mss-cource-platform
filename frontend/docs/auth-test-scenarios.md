# 認証機能テストシナリオ

## 1. サインアップ

### 正常系
- [ ] 新規ユーザーでサインアップ → 成功 → ホームへリダイレクト
- [ ] サインアップ後に認証状態になっている
- [ ] ヘッダーにユーザー名が表示される

### 異常系
- [ ] 空のフォーム送信 → バリデーションエラー
- [ ] 無効なメールアドレス → バリデーションエラー
- [ ] 弱いパスワード → バリデーションエラー
- [ ] パスワード不一致 → バリデーションエラー
- [ ] 既存のメールアドレス → APIエラー
- [ ] 利用規約未同意 → ボタン無効

## 2. ログイン

### 正常系
- [ ] 正しい認証情報でログイン → 成功 → ホームへリダイレクト
- [ ] Remember me でログイン → 次回メールが保存される
- [ ] リダイレクトパラメータ付きログイン → 指定ページへリダイレクト

### 異常系
- [ ] 空のフォーム送信 → バリデーションエラー
- [ ] 無効な認証情報 → APIエラー
- [ ] 存在しないユーザー → APIエラー

## 3. ログアウト

- [ ] ログアウト → 認証状態が解除される
- [ ] ヘッダーがログイン前の状態に戻る
- [ ] localStorageがクリアされる
- [ ] 保護されたページにアクセス → ログインページへリダイレクト

## 4. プロフィール

### 表示
- [ ] プロフィール情報が表示される
- [ ] アバター画像が表示される
- [ ] 役割バッジが表示される

### 編集
- [ ] プロフィール情報を変更 → 保存 → 反映される
- [ ] キャンセル → 変更が破棄される

### パスワード変更
- [ ] 正しいパスワードで変更 → 成功
- [ ] 誤った現在のパスワード → エラー
- [ ] 弱い新しいパスワード → バリデーションエラー

## 5. ルートガード

### 認証必須ページ
- [ ] 未ログインで /profile → ログインページへリダイレクト
- [ ] ログイン後に元のページへリダイレクト
- [ ] リダイレクト時にトースト通知が表示される

### ゲスト専用ページ
- [ ] ログイン済みで /auth/login → ホームへリダイレクト
- [ ] ログイン済みで /auth/signup → ホームへリダイレクト
- [ ] リダイレクト時にトースト通知が表示される

### 講師専用ページ
- [ ] 一般ユーザーで /instructor/dashboard → アクセス拒否 → トースト表示
- [ ] 講師で /instructor/dashboard → アクセス許可

### 管理者専用ページ
- [ ] 一般ユーザーで /admin/dashboard → アクセス拒否 → トースト表示
- [ ] 講師で /admin/dashboard → アクセス拒否 → トースト表示
- [ ] 管理者で /admin/dashboard → アクセス許可

## 6. トークン管理

- [ ] ページリロード → 認証状態が保持される
- [ ] トークン期限切れ → 自動ログアウト（10分ごとのチェック）
- [ ] 401エラー → ログインページへリダイレクト
- [ ] トークンあり・ユーザー情報なし → 自動的にユーザー情報取得

## 7. UX

- [ ] ローディング状態が表示される
- [ ] エラーメッセージが適切に表示される
- [ ] 成功メッセージがtoastで表示される
- [ ] フォームバリデーションがリアルタイムで動作する
- [ ] Toast通知が適切なアイコンとカラーで表示される
- [ ] Toast通知が自動的に消える（3秒後）

## 8. Toast通知の確認

### 表示確認
- [ ] Info toast（青）が正しく表示される
- [ ] Success toast（緑）が正しく表示される
- [ ] Warning toast（黄）が正しく表示される
- [ ] Error toast（赤）が正しく表示される

### タイミング確認
- [ ] ログイン成功時にSuccess toastが表示される
- [ ] サインアップ成功時にSuccess toastが表示される
- [ ] プロフィール更新時にSuccess toastが表示される
- [ ] 権限エラー時にError toastが表示される
- [ ] 認証必須ページへのアクセス時にWarning toastが表示される

## 9. セッション管理

- [ ] 新しいタブで開く → 認証状態が共有される
- [ ] ログアウト後、他のタブでも認証状態が解除される
- [ ] 初期化は一度だけ実行される（initialized フラグの確認）

## 10. エラーハンドリング

- [ ] ルーターエラー → エラーtoastが表示される
- [ ] API通信エラー → 適切なエラーメッセージが表示される
- [ ] ネットワークエラー → タイムアウト（10秒）後にエラー
- [ ] 422バリデーションエラー → エラーメッセージがtoastで表示される

## 実施手順

1. **事前準備**
   - バックエンドAPIが起動していることを確認
   - フロントエンド開発サーバーが起動していることを確認
   - テスト用ユーザーアカウントを準備

2. **テスト実施**
   - 上記の各テストケースを順番に実行
   - 各項目でチェックマークを付ける
   - 問題があれば詳細を記録

3. **結果記録**
   - 全てのテストケースがパスすることを確認
   - 問題があった項目は修正後に再テスト

## 備考

### パフォーマンス
- トークンチェックは10分ごと（調整可能）
- 不要なAPI呼び出しを避ける
- ローディング状態を適切に表示

### セキュリティ
- トークンの期限切れを検知
- 401エラーで自動ログアウト
- XSS対策（Vue が自動でサニタイズ）
- パスワードバリデーション（8文字以上、大文字・小文字・数字）

### 今後の改善
- E2Eテストの追加（Playwright, Cypress）
- ユニットテストの追加（Vitest）
- リフレッシュトークンの実装
- OAuth連携（Google, GitHub等）
- パスワードリセット機能のテスト追加
